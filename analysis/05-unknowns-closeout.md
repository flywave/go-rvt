# 未知收口批次（A–J）— 第 4 轮

对应 rvt-format.md §4 未知队列逐项处置；证据=E2 objdump/nm + E3 双样例。

## A. +353 页回收 ✅（实用级）

规则定案：**next_rec = member_start + ownLen − 8**（ownLen=压缩长+8 CRC）；
解压失败时 **span += 353 重试**（R29 陈旧索引）；字典链（32KB 窗口）继续有效；
失步后按 `markA=0x0E47` 前缀重同步。结果：
- 2023 Partitions/13：**133 页 / 14.8MB**（77 clean + 51 stale353 + 5 resync），较旧 walker +7.6MB
- 2022 Partitions/8：**151 页 / 19.0MB**（101+50）
- 逻辑流暂存 `/tmp/rvt-partition-{2022,2023}.bin`；全 1060 页仍需终结器回链扫描（下轮）

## B. 签名 64B 块 🟡（定性收口）

64B ≠ sha512/sha256/blake2b 之任何前缀（对页数据/前缀/记录多候选扫描无匹配）——
**非裸内容哈希，定性为非对称签名块**（RSA-512 尺寸；公钥/算法未见）。串长34=UTF-16
"Data generated by Autodesk® Revit®" ✓（R27 复核）。算法精确验证=需签名验证路径反编译（挂账）。

## C. [counter][size] 记录循环 🟡

- 路由定案：每元素 → **OdBmDepositId（=u64 Handle 薄包装，E1 BmDepositId.h）×3 三元组**
  （`array<OdBmDepositId,3>`）；`splitElements@0xa0fa6`/`populatePartition`/`splitElementIntoParts`
  负责元素→deposit 拆分；I/O 在 `BmIODepositPE.cpp`（TB_LoaderBase，**平台扩展外部**）
- 字节级 [u32 counter][u32 size] 循环消费点在 PE 内（未反编译）——路由层已闭环，字节层挂账

## D. ElementId 裸 id 🟡

链路：fieldType13 → c_valueReader→ **objectReader（队列 IdReference）→ OdDbStub → OdBmObjectId**；
裸值经 DynamicQueue 事后回填。盘上形态=队列 id（宽度在 PE/objectReader 深处，挂账）。

## E. String/Guid reader ✅（TB_Common.tx）

- **GuidReader：raw 16B**（`mov $0x10,%edx; stream->read(…,16); OdGUID(bytes)`——无前缀无换序）
- **StringReader：i32 长度 + raw 字节**（Int32Reader→StringBaseReader 按该长度读；
  编码=OdString 默认（Linux 侧疑 UTF-8）[?]）

## G. 页记录/CRC/ElemTable 残项 🟡

- 页 kind=4 常规/5 小页/6·7 对齐页（M3.5 已录）；class=101/102/103 子流标签 ✓
- CRC findBySize 参数表：PE 内，挂账
- ElemTable magic `5a 05 54 20`=非 ASCII 语义串 [?]；depA/depB=非类索引（R35 维持）
- deposit Field91：非 Index4Enum 空间（R33）；语义随 PE 挂账
