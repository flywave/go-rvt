# go-rvt — RVT（Autodesk Revit）纯 Go 解析库

RVT 格式的分析与实现**独立于 go-dgn**（DWG/DGN 项目），同级仓库。
go-dgn 侧仅保留指引（`go-dgn/analysis/04-rvt/README.md`）。

## 实现路线

1. ✅ **M1 元数据层（已落地）**：`internal/cfb`（嵌套递归）→ `bfi`（BasicFileInfo TLV）
   → `rvt.Open`（识别+版本门控字段+流清单+TransmissionData XML）→ `cmd/rvtinfo` JSON；
   双真实样例（2022/2023）端到端测试绿
2. ✅ **M2 表层（已落地）**：`internal/zg`（单 gzip 成员解压，宽容 Revit 非标准 footer）
   → Global/*+Formats/* 表解压（2023 全 7 表）→ Contents 魔数帧（GLOBAL 索引）
   → PartitionTable 工作集名；勘误见 findings R20b/R21
3. ✅ **M3 分区容器层（已落地，REA+样例双证）**：`rvt/partition.go` ——
   Partitions/<n> = 44B 头(v9) + gzip 页链 + 变长页尾(OdBmFileCRC)；
   trial 恢复损坏页；103B deposit 索引区 + 对象区(raw)；
   REA 证据：readPartitions/PageReader/verifyAndCutCRC/ObjectStreamReader 栈（findings R23–R25）
4. ✅ **M3.5 分区索引/子流层（已落地，双样例逐字节定案）**：`rvt.ReadPartition` ——
   12B 固定头 + **32B 页记录内联索引**（ownLen/prevLen 页长链、markA/markB 每文件标记、
   class=101/102/103 子流标签）；**3 条交错逻辑子流**按类重组（仅验证页入流）；
   签名块（"Data generated by Autodesk® Revit®"）与终结器识别；
   103B deposit 记录检测（双版本布局适配）；
   损坏分类三态（verified / corrupt_data / unreadable）+ **R29：+353 系统性索引陈旧发现**
   （修正 R21 随机损坏解读）；合成夹具端到端测试
   - 未竟：对象信封全长解码（ObjectPtrReader 在外部库）；干净样例复核（R21/R29）
5. ✅ **M4 对象记录层（已落地，第 4 轮 REA 报告 R30–R44 驱动）**：
   `rvt/classindex`（2022/2023 类索引全表嵌入：1398@2023=1340@2022=OdBmElementHeader，
   按版本重编号）→ `rvt/objects.go` 记录环 walker
   （`[counter][size][body][echo]`，class-101 验证：77,251/58,819 条 ElementHeader，
   100% 覆盖）→ `rvt/elemtable.go`（8,276 条，footer 内嵌分区末条 deposit counter
   =串联键实锤）→ `rvt/partition.go` R40 stale 回收（逻辑流 +20.3/+15.4MB）
   → UnitSystem 尾 + ProjectInformation ZIP 元数据
   - 未竟：per-class 属性级解码（需 per-class reader 元数据）；G* 字段级序列化（下轮战役）
6. ✅ **M4.5 ElementHeader 属性级解码（已落地，第 5 轮 REA）**：
   生成 reader 反汇编 → 静态 schema 全量定案（R49：RegenHistory/6×ElementId(i32)/
   ViewRules 位掩码/AbFlags/ClassDefRef/2×CondInt16）→ `rvt/elements.go`
   DecodeElementHeader + **元素类身份普查**（ClassDefRef i16→真实类：2023 解出
   77,213/77,251 条，GStyleElem/CategoryElem/CurveElem…模型构成直接可见，R50）；
   动态属性段=位压缩 token 流（R52，有界挂账）
   - 未竟：动态段 token 位格式；G* 字段级序列化（下轮战役主目标）
7. ✅ **M5 几何路由层（已落地，第 6 轮 REA）**：class-103=几何 deposit 流定案——
   18B 定形目录（counter 与 class-101 同域 100% 联动）+ G 对象区（i16 信封；
   2023: GLine×17803/GElement×5868/Geometry×1652…）；`rvt/geometry.go`
   ParseGeometryIndex/GMarkerCensus；G* reader schema 链提取
   （GNode/GRep/GElement/GPoint/GLine/GBrep/GEdge/GEdgeLoop，R54）
   - 未竟：OBJREF 目标类 schema（Coord/bbox/GInfo）；G 对象逐个定界解码
8. ✅ **M5.5 G 数据库目录层（已落地，第 7 轮探针）**：class-103 G 区的 6B 像目
   `[i16 class][u32 id]` 层扫通（2023: 2,238 像）——**BRep 拓扑以
   OdBmFace/OdBmEdge 交替 id 序列目录化**；GElement 组按 deposit counter 键控；
   Geometry(2160) 内联 f64 bbox（英尺）；`rvt/geometry.go` ScanGCatalogRuns
   - 未竟：像目→对象 blob 指向；OBJREF 目标类；G 对象完整解码

## 包结构

```
internal/cfb/   OLE/CFB 只读（全路径递归；合成夹具 cfbtest + 真样例测试）
internal/zg/    单 gzip 成员解压（ByteReader 精确边界；footer 宽容+状态位）
bfi/            BasicFileInfo TLV 解析
rvt/            Open/Metadata + ReadPartition + 对象记录层（ElemTable/记录环普查）
rvt/classindex/ 按版本类索引表（2022/2023 CSV 嵌入；Index4Enum→OdBm* 类名）
cmd/rvtinfo/    CLI：rvtinfo <file.rvt> → JSON
```
